# API Response Privacy Matrix

This matrix classifies every NestJS controller and FanPass Console BFF response before Beta. It is intentionally route-level rather than DTO-level because the immediate release risk is accidental public, provider, local-debug, or one-time-secret exposure when API/BFF handlers drift.

Run `npm run security:api-privacy` after adding, removing, or changing API controller handlers, FanPass Console BFF handlers, or response exposure.

## Classification Rules

| Classification          | Meaning                                                             | Beta rule                                                                                               |
| ----------------------- | ------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------- |
| `PUBLIC_SYSTEM`         | Public liveness or service metadata.                                | No user, ticket, payment, wallet, scanner, or organizer data.                                           |
| `PUBLIC_CATALOG`        | Public event or catalog data.                                       | No user identity, payment data, QR payloads, scanner nonces, or private organizer state.                |
| `PUBLIC_MARKET`         | Public aggregated market data.                                      | Aggregates only; no order owner, payment, wallet, or session data.                                      |
| `AUTH_SESSION`          | Auth/session exchange response.                                     | May return session credentials only through an auth boundary; no public caching.                        |
| `FAN_PRIVATE`           | Fan-owned private response.                                         | Must be scoped to the authenticated fan or admin.                                                       |
| `STAFF_PRIVATE`         | Gate-staff operational response.                                    | Must be scoped to assigned event/gate staff or admin; no fan PII beyond required status.                |
| `ORGANIZER_REDACTED`    | Organizer/admin operational response with organizer-safe redaction. | Organizer access must be event-scoped; admin may receive fuller data where explicitly implemented.      |
| `ORGANIZER_SECRET_ONCE` | Organizer/admin response containing a one-time operational secret.  | Secret must be returned only once and not stored in URLs or normal operations snapshots.                |
| `ADMIN_PRIVATE`         | Admin-only private response.                                        | Must require the `ADMIN` role.                                                                          |
| `PROVIDER_INGRESS`      | External provider webhook or callback ingress.                      | Must verify provider signatures outside local development and return only minimal acknowledgement data. |
| `DEVICE_INGRESS`        | Authenticated venue device command ingress.                         | Must verify the device credential and return only the minimum gate decision; never expose fan PII or raw signing material. |
| `LOCAL_DEBUG`           | Local/prototype control response.                                   | Must remain disabled or admin/organizer gated outside local development.                                |
