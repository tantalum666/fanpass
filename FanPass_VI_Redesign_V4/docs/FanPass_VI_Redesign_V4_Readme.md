# FanPass VI Redesign V4 — Clean Layout Fix

This version fixes the visual issues from V3:

1. **Removed all distracting decorative background lines** from the app icon and brand sheet.
2. **Kept NFC/proof waves inside UI components only**, instead of using them as large background strokes.
3. **Fixed the ticket concept layout** so that all text stays inside the card boundary.
4. **Moved the Proof & History block into a contained panel** to avoid overflow.
5. **Kept the V3 brand direction**: Premium Concert Pass × Web3 Trust Layer.
